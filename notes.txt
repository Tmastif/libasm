
assembly variables: 16 in total global 64 bit registers

calling conventions:
Argument	    Register
1st	            rdi
2nd	            rsi
3rd	            rdx
4th	            rcx
5th	            r8
6th	            r9
return value	rax

Free to use (scratch)
rax, rcx, rdx, rsi, rdi, r8–r11

the caller saves them if it needs the value after the call.
- Can use them freely, without saving anything.
- But if a function is called, their values are gone afterwards.
- If the caller needs one after a call, the caller must save it first. (pushing and popping)

Callee-saved
the callee saves them, if it wants to use the register
rbx, rbp, r12–r15
- These survive calls: the function you call promises not to change them.
- But to use one, we must save the caller’s value first (push) and restore it before returning (pop).
because the caller functions might be using them.


different sizes of same variables
rax (8 bytes), eax (4), ax (2), al (1)

The same pattern for every register:
64-bit	32-bit	16-bit	8-bit (low)
rax	eax	ax	al
rbx	ebx	bx	bl
rcx	ecx	cx	cl
rdx	edx	dx	dl
rsi	esi	si	sil
rdi	edi	di	dil
r8	r8d	r8w	r8b
… r15	r15d	r15w	r15b


Match the register size to the C type you’re reading or writing:

C type	            Size	    Register part
char	            1 byte	    cl, dl, al…
int     	        4 bytes	    ecx, edx, eax…
size_t, pointers	8 bytes	    rcx, rdx, rax…
